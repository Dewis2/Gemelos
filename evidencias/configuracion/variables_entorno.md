# Variables de entorno

`render.yaml` declara `ENVIRONMENT`, `DATABASE_URL`, `CORE_REPOSITORY`, `DEMO_REPOSITORY`, `DATA_ROOT`, `ML_MODEL_PATH`, `DEMO_ML_METADATA_PATH`, `MQTT_ENABLED`, `AUTH_REQUIRED`, `AUTH_USERNAME`, `AUTH_SECRET`, `AUTH_PASSWORD_HASH`, `SUMO_ASSETS_ROOT`, `SUMO_REPORT_PATH`, `CORS_ORIGINS` y `VITE_API_URL`. Los valores de autenticación y conexión se configuran en Render. Aquí se documentan los nombres; no se incluyen secretos ni URLs de base con credenciales.
