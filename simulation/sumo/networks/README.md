# Red OSM de la simulación exploratoria

`huancayo-ferrocarril-osm-20261113.osm.xml` es una extracción de
[OpenStreetMap](https://www.openstreetmap.org/copyright), obtenida el 13 de
noviembre de 2026 mediante:

`https://api.openstreetmap.org/api/0.6/map?bbox=-75.220,-12.073,-75.200,-12.060`

SHA-256 del archivo OSM: `141c9f6ede92f5015b4687f8a69d73c575e35b2eca72acca2bdd4b7712346b29`.
`huancayo-exploratory.net.xml` es una red derivada con SUMO `netconvert` 1.28.0.
El reporte `frontend/src/data/osm-exploratory-report.json` registra los hashes de
la red, las rutas y el GeoJSON utilizado en el mapa.

Los datos OSM y la geometría derivada se distribuyen bajo
[ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), con atribución a
© OpenStreetMap contributors. La licencia MIT del código del proyecto no modifica
la licencia de estos datos. Esta red no es cartografía municipal certificada.
